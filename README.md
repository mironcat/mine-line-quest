# MINE-LINE

ASCII-квест про шахтёра: исследуйте уровни, добывайте дерево, камень и железо, покупайте снаряжение у торговца и сразитесь с королём-гоблином.

Подробности и прохождение — в [вики](https://github.com/mironcat/mine-line-quest/wiki).

## Скачать и запустить (Windows)

1. Откройте страницу [Releases](https://github.com/mironcat/mine-line-quest/releases).
2. Скачайте `mine-line-quest.exe` из версии **1.0**.
3. Запустите файл двойным щелчком. Установка и Python не нужны — всё внутри одного exe.
4. Введите имя героя и нажмите любую клавишу, чтобы начать игру.

Если Windows SmartScreen предупреждает о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Управление

| Клавиша | Действие |
| --- | --- |
| `a` / `ф` | шаг влево |
| `d` / `в` | шаг вправо |
| `e` | взаимодействие: рубить, добывать, говорить, атаковать |
| `z` / `я` | защита в бою |
| `i` | показать инвентарь |
| `q` | выход из игры |

## Запуск из исходников

Нужен Python 3.9 или новее. Сторонние библиотеки не требуются.

```bash
python start_game.py
```

Запускать из корня проекта: игра сама находит папки `heroes/` и `screens/`.

## Сборка exe

```bash
python release.py
```

Либо двойной щелчок по `release.bat`. Готовый файл: `dist/mine-line-quest.exe` (около 8 МБ).

- PyInstaller при необходимости устанавливается автоматически; `--no-install` отключает установку.
- Состав сборки задаёт `make_exe.spec`; папки `heroes/` и `screens/` вшиваются в exe.
- В собранном exe отладочный режим выключен. Включить принудительно: `set MINE_LINE_DEBUG=1`.
- Дополнительные аргументы PyInstaller передаются после `--`, например: `python release.py -- --log-level=WARN`.

## Структура проекта

```
start_game.py        точка входа, игровой цикл
release.py           команда релизной сборки exe
release.bat          то же самое для запуска в проводнике
make_exe.spec        конфигурация PyInstaller
modules/             логика игры и персонажи
heroes/              ASCII-спрайты
screens/             уровни
```
